# Drive 续传工作台

本机 FastAPI + HTML/CSS + 原生 JavaScript 上传工具。Windows / Python 3.10+。

## 首次安装与启动

1. 安装 Python 3.10 或更新版本，确保命令行可以运行 `python`。
2. 下载或克隆本仓库到本机，双击 **安装依赖.cmd**，创建 `.venv` 并安装依赖。
3. 在 Google Cloud 项目中启用 Google Drive API，配置 OAuth 同意屏幕，并创建“桌面应用”OAuth 客户端。将下载的客户端 JSON 保存在仓库以外的位置。如果应用处于测试状态，需要把登录账号添加为测试用户。
4. 双击 **启动工作台.cmd**，在网页中填写原 JSON 路径，检查配置并连接 Google，然后设置本地来源和云端目标目录。

仓库不包含客户端 JSON、授权令牌、本地上传记录或虚拟环境。请使用自己的 Google Cloud 配置；不要将凭据提交到 Git。

## 日常打开与关机后恢复

双击 **启动工作台.cmd**，浏览器将打开 **http://127.0.0.1:8787**。关闭网页不停止后台上传；关闭服务终端会请求暂停任务。重新启动后任务保持暂停，点击继续向 Google 查询进度。不要开启多个后台实例或使用开发服务器自动重载。

后台方式启动时可双击 **停止工作台.cmd** 正常停止服务；会保存并暂停未完成任务。不要通过删除data目录来停止上传。

## 使用

1. 填写原有桌面应用 OAuth 客户端 JSON 的完整路径，点击“检查配置”。程序只读原文件，不将 JSON 或 client_secret 复制到 data、日志、数据库。
2. 点击“连接 Google”，在系统浏览器完成账号登录与授权。为了使用已有云盘目录，本应用请求 Drive 文件管理权限；页面显示已连接账号。已授权的本机令牌可用于后台刷新，令牌和上传会话采用 Windows DPAPI 加密保存，绑定当前 Windows 用户。
3. 填写本地源文件夹，例如 `G:\Datasets\coco2017\_archives`，点击确认。文件可以从该文件夹拖入，也可以填写完整文件路径。
4. 选择云端目录，或粘贴文件夹链接/ID，再点击确认。初次使用需要自行选择目标；以后会恢复本机保存的目录设置。
5. 拖入文件、整个文件夹，或点击“选择文件/选择文件夹”。文件夹先扫描，显示文件数、文件夹数和总大小，可打开“文件清单”查看。核对实际路径和云端目标后点击开始，也可“全部开始”。

浏览器不能提供拖入文件的真实 Windows 路径。普通文件使用“源目录+文件名及大小”匹配；拖入文件夹则匹配源目录下的同名文件夹，或匹配源目录本身。请核对队列显示的实际路径；同名文件夹的真实来源无法单凭拖拽名称判定。“选择文件夹”还会核对最多64个文件的相对路径和大小。注册具体文件夹，不要注册整个盘符。

## 整个文件夹上传

例如上传 `G:\Datasets\coco2017`：源目录填写 `G:\Datasets`（或 `G:\Datasets\coco2017`），云端目标选择 `Datasets`，将本机 `coco2017` 文件夹拖入上传区。开始后云端结构为 `Datasets/coco2017/...`，保留所有层级、相同文件名的不同路径及空目录。不打包、不复制源文件；隐藏文件也会扫描。若只想上传ZIP，请继续使用原来的文件上传方式。

支持一次拖入多个文件夹，以及文件与文件夹混合拖入。也可在“填写本地路径”中选择“整个文件夹”并输入完整路径，适合空文件夹或浏览器选择不便的情况。推荐使用 Edge / Chrome。

每个文件夹只在队列显示一个任务，详情展示正在处理的相对路径，文件清单每页100条。文件列表单独持久保存，不受普通文件一次200个的限制。扫描不向云端写入；可暂停、取消扫描。扫描中断后继续会重新扫描；扫描完成后续传沿用原清单。扫描后新增文件不自动加入，需另建任务；删除或修改待上传文件会停止对应任务。

同名云端文件夹会复用，但多个同名目录或同名非目录会报错。每个文件仍单独断点续传并核验大小和MD5；相同内容可跳过，不同内容不覆盖。后台重启后点击继续，会恢复目录映射和当前文件的会话。目录创建使用预分配ID处理网络中断，避免因创建响应丢失而生成重复目录。取消不回滚已经建立的云端目录和完成文件。

遇到符号链接、目录联接、无法读取的文件、工作台自身文件或当前OAuth JSON会明确停止，不会默默漏传。文件夹扫描和上传始终只读源文件。

## 任务控制

- **暂停**：先显示暂停中，当前请求结束后进入已暂停，保留 Google 续传会话。网络请求超时最长约一分钟，暂停并非瞬间终止远端传输。
- **继续**：查询 Google 已确认的字节位置后继续，不盲目重发最后一块。
- **取消**：停止上传及重试，不删除本地文件，也不删除已完成的云端文件；取消恰逢最后一块完成，可能显示校验完成。未完成的远端会话由 Google 失效，取消不承诺可恢复。
- **会话失效**：明确标记“会话失效”，点击“重新上传”并确认后才从头开始。
- **网络波动**：指数退避、显示等待重试；连续失败达到上限后进入需要处理，再点击继续。退避等待可被暂停/取消唤醒。
- **校验**：本地 MD5、完整字节大小、云端名称、父目录和所有权均通过后才显示“已完成”。100% 已确认字节还不等于完成校验。

默认8MiB分块，支持4/8/16MiB；默认同时上传1个任务，可切换2个。文件夹内的文件依次上传。大文件只读分块，不生成整文件临时副本。每次继续会确认源文件长度与mtime，变化时拒绝复用旧会话。相同源指纹、账号、目标的任务会复用队列项；同名同MD5的云端文件可直接校验跳过，同名异内容则停止，不自动覆盖。

## 主题及实时状态

右上角可切换浅色、深色、跟随系统，偏好保存在当前浏览器。WebSocket每秒推送已确认进度、平滑速度、剩余时间及脱敏日志。页面刷新或WebSocket断开不会取消后台任务，重新打开可以恢复查看。前端与后台同机；不支持其他电脑的本地文件路径。

## 数据边界

`data/jobs.sqlite3` 保存任务、源路径、文件指纹、已确认进度和事件；`data/secrets/*.dpapi` 仅保存加密令牌或上传会话。不保存原始OAuth JSON副本，也不额外保存client_secret。JSON路径可记住；原JSON必须仍在原路径，才能在令牌刷新时读取客户端配置。

取消勾选“记住原文件路径”后再检查配置，后端仅在本次运行中记住路径，浏览器也不再缓存路径；服务重启后需要重新填写。此前已授权令牌仍为独立加密缓存，不包含client_secret。

服务仅绑定127.0.0.1，检查Host、Origin、本机会话cookie与防伪标记。API没有源文件删除、云端删除或匿名网络上传功能；本机其他程序依然应被视为拥有当前用户权限。

## 安装与维护

运行“安装依赖.cmd”可创建或更新本机独立 `.venv` 环境；运行“运行测试.cmd”执行离线故障模拟。测试不会向Google上传文件。前端事件测试需要 Node.js，可另外执行 `node tests/test_frontend_folders.cjs`。

项目模块：`app/auth.py` 授权及最小令牌缓存；`app/drive.py` Google API；`app/engine.py` 队列和可控worker；`app/storage.py` SQLite/DPAPI；`app/main.py` FastAPI与WebSocket；`static/` 前端。

启动脚本会检查端口，已有实例时不再创建上传worker。`python run.py --port 8788` 可指定其他端口，但同一data目录仍只允许一个实例。更换端口后首次授权使用对应本机回调地址。

## 验证范围

离线测试包含：部分块已被Google接收后的断线、暂停确认、取消边界、最终提交与取消竞争、服务重启恢复、会话失效、重复任务、同名冲突、源文件变化、凭据不复制、DPAPI、路径范围及本地API/WebSocket访问限制。真实账号的授权/目录读取和实际浏览器界面由搭建过程核实；大文件上传受实际网络和Google限额影响。
